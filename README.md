# Canvas

**Canvas** — статичний каталог frontend-робіт, інтерактивних експериментів та невеликих вебпроєктів.

Проєкт працює без PHP та backend: головна сторінка завантажує перелік робіт із `data/works.json`.

## Структура проєкту

```text
canvas/
├── index.html                 # Головна сторінка каталогу
├── README.md                  # Документація
├── data/
│   └── works.json             # Дані про всі роботи
├── assets/
│   ├── css/style.css          # Стилі каталогу
│   ├── js/app.js              # Завантаження JSON, пошук і фільтри
│   └── previews/              # Зображення та GIF-прев'ю
└── works/
    └── 001/
        ├── index.html         # Сторінка окремої роботи
        ├── style.css
        └── script.js
```

## Додавання нової роботи

1. Створіть папку для роботи, наприклад `works/002/`.
2. Додайте до неї `index.html`, `style.css` та `script.js`.
3. За потреби додайте зображення попереднього перегляду до `assets/previews/`.
4. Додайте новий об'єкт до масиву в `data/works.json`:

```json
{
  "id": "002",
  "title": "Назва роботи",
  "category": "Інтерфейси",
  "tags": ["CSS", "Анімація"],
  "preview": "assets/previews/002.gif",
  "url": "works/002/"
}
```

### Поля JSON

| Поле | Опис |
|---|---|
| `id` | Унікальний ідентифікатор роботи |
| `title` | Назва роботи в каталозі |
| `category` | Категорія для фільтрації |
| `tags` | Масив тегів |
| `preview` | Шлях до PNG, JPG, WebP або GIF |
| `url` | Посилання на сторінку роботи |

Якщо `preview` не вказано, картка покаже стандартну заглушку. Якщо `url` не вказано, каталог використовуватиме `works/{id}/`.

## Запуск локально

Не відкривайте `index.html` безпосередньо через `file://`: браузер може заблокувати завантаження JSON.

Запустіть будь-який локальний статичний сервер. Наприклад, за допомогою Python:

```bash
python -m http.server 8000
```

Після запуску відкрийте в браузері:

```text
http://localhost:8000
```

Також можна скористатися розширенням Live Server у Visual Studio Code.

## Технології

- HTML5
- CSS3
- JavaScript
- jQuery 3.7.1 (CDN)
- JSON

PHP, база даних, backend та збирач проєкту не потрібні.

## Принцип роботи

- Кожна робота зберігається в окремій папці.
- Кожна робота має власні HTML, CSS та JavaScript.
- Головна сторінка читає лише метадані з JSON.
- Каталог відповідає за відображення карток, пошук і фільтрацію.
- Для публікації достатньо завантажити всю папку на статичний хостинг, наприклад GitHub Pages.
