# xCanvaz

**xCanvaz** - персональна колекція frontend-робіт, інтерактивних експериментів та невеликих вебпроєктів, створених **Володимиром Батраковим**.

Тут зібрані різноманітні роботи, що демонструють практичний досвід, технічні навички, творчі ідеї та експерименти з вебтехнологіями.

Кожна робота має власну концепцію, реалізацію та візуальний стиль. Колекція постійно поповнюється новими проєктами й експериментами.
